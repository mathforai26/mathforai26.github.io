\begin{exercisechunk}
\item \textbf{When does a reusable jump table reduce the total cost?}\suppmark
\label[exercise]{ex:l14-pointer-doubling}
\exerciseprofile{2}{2}{2}{\exproof\quad\excalculation\quad\exinterpretation}{%
Count the preprocessing and query operations that the asymptotic depth
comparison suppresses.}
Let $\cD$ be a nonempty finite set of size $M$, let $p:\cD\to\cD$, and
fix an integer $J\ge1$. A query $(x,K)$ asks for $p^K(x)$, where
$x\in\cD$ and $p^K$ denotes $K$ successive applications of $p$.
Both methods below are given the table $q_0$, indexed by $u\in\cD$,
whose entry $q_0[u]$ stores $p(u)$.

\emph{Direct iteration} answers each query by starting at $x$ and applying
$q_0$ exactly $K$ times. The \emph{jump-table method} first constructs
and retains tables $q_1,\ldots,q_J$ with entries
\[
 q_{\ell+1}[u]=q_\ell[q_\ell[u]],
 \qquad u\in\cD,\quad \ell=0,\ldots,J-1.
\]
You may use $q_\ell[u]=p^{2^\ell}(u)$. A \emph{table update} computes and
stores one new entry $q_{\ell+1}[u]$ by this rule. Charge one unit for
the complete update, including its table reads. A \emph{query lookup}
retrieves one stored entry $q_\ell[z]$ and replaces the current query
state $z$ by that value; charge one unit for each query lookup.
Total cost is the number of preprocessing updates plus query lookups.
All $M$ updates at a fixed level may run in parallel, but each update
contributes one unit to total cost.

The jump tables are constructed once and reused across the batch.
Each query is evaluated independently: neither method reuses answers or
intermediate query results from earlier queries. Ignore storage costs and
the work of reading the binary digits of $K$.
\begin{enumerate}[(a),beginpenalty=10000]
\item Let $K=\sum_{\ell=0}^J b_\ell2^\ell$, where
$b_\ell\in\{0,1\}$. The jump-table method starts at $z=x$ and performs
one lookup $z\leftarrow q_\ell[z]$ for each $\ell$ with $b_\ell=1$.
Prove that these lookups return $p^K(x)$ in any order, using exactly
$\sum_{\ell=0}^J b_\ell$ lookups.
\item Consider the exhaustive batch containing one query for every
$K\in\{0,\ldots,2^{J+1}-1\}$, with arbitrary initial states.
Prove that the total costs are
\[
 C_{\mathrm{direct}}=2^J(2^{J+1}-1),
 \qquad
 C_{\mathrm{jump}}=MJ+(J+1)2^J.
\]
\item Suppose instead that the same input map must answer $Q$ queries, each
with iteration count
$K_{\max}=2^{J+1}-1$ but possibly with a different initial state, where
$Q\ge1$ is an integer. Prove that
\[
 C_{\mathrm{direct}}=QK_{\max},
 \qquad C_{\mathrm{jump}}=MJ+Q(J+1).
\]
Deduce that the jump-table method has strictly smaller total cost if and
only if
\[
 Q>\frac{MJ}{K_{\max}-J-1},
 \qquad J=\log_2(K_{\max}+1)-1.
\]
\item Compare the exhaustive batch in part~(b) with the maximum-length batch
in part~(c) by giving the mean number of jump-table query lookups per
query in each batch. Explain why performing the updates within each
preprocessing level in parallel can reduce sequential depth while still increasing total cost
when too few queries reuse a large table.
\end{enumerate}
\end{exercisechunk}
