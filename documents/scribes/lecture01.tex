\section{The inference problem}

Given a token prefix $x_{<t}=(x_0,\ldots,x_{t-1})$, a language model returns a
categorical distribution for the next token:
\begin{equation}
x_{<t}\longmapsto p_\theta(\,\cdot\mid x_{<t}).
\end{equation}
An inference algorithm selects $x_t$ from this distribution, appends it to the
prefix, and repeats. Thus the model and the rule used to decode from it are
distinct objects.

Let the vocabulary have size $V$, and identify token $x_t\in[V]$ with the
standard basis vector $e_{x_t}\in\{0,1\}^V$. Include a beginning-of-sequence
token $x_0$. For $T$ prediction positions, define $Z\in\{0,1\}^{T\times V}$ by
\begin{equation}
Z_{t,:}=e_{x_{t-1}}^\top,
\qquad t=1,\ldots,T.
\end{equation}
With an embedding matrix $E\in\R^{V\times d}$ and additive absolute-position
vectors $P\in\R^{T\times d}$, the input is
\begin{equation}
H^0=ZE+P,
\qquad
H^0_{t,:}=E_{x_{t-1},:}+P_{t,:}.
\end{equation}
The one-hot notation makes the map explicit; an implementation performs a row
lookup in $E$.

\paragraph{Where is position added?}
Equation (1.3) describes additive absolute positions. They are added once,
before the first transformer block; they are not added again in every block.
Other position mechanisms enter the computation differently. RoPE applies a
position-dependent rotation to queries and keys in each attention layer that
uses RoPE. A relative-position bias is likewise added to the attention logits
in each layer that uses it. These are alternative architectural choices; the
symbol $P$ in (1.3) does not also stand for RoPE.

\section{One fully specified decoder block}

Suppose $H^\ell\in\R^{T\times d}$ enters layer $\ell$. Consider a
pre-normalized block with $h$ attention heads of width $d_h$. For head
$a\in[h]$, let
\begin{align}
U&=\LN_{\ell,1}(H^\ell), \\
Q_a&=UW^Q_{\ell,a},
&K_a&=UW^K_{\ell,a},
&V_a&=UW^V_{\ell,a}, \\
A_a&=\softmax_{\mathrm{row}}\!\left(
\frac{Q_aK_a^\top}{\sqrt{d_h}}+M\right),
&O_a&=A_aV_a,
\end{align}
where
\begin{equation}
W^Q_{\ell,a},W^K_{\ell,a},W^V_{\ell,a}\in\R^{d\times d_h},
\qquad
M_{ij}=\begin{cases}
0,&j\leq i,\\
-\infty,&j>i.
\end{cases}
\end{equation}
The softmax acts row by row. The causal mask makes the attention weight of
every future position exactly zero. Concatenate the head outputs and apply the
first residual connection:
\begin{equation}
G=H^\ell+[O_1\mid\cdots\mid O_h]W^O_\ell,
\qquad W^O_\ell\in\R^{hd_h\times d}.
\end{equation}
The positionwise feed-forward sublayer and second residual connection give
\begin{align}
R&=\LN_{\ell,2}(G),\\
H^{\ell+1}
&=G+
\phi\!\left(RW^1_\ell+\mathbf 1(b^1_\ell)^\top\right)W^2_\ell
+\mathbf 1(b^2_\ell)^\top,
\end{align}
with
\begin{equation}
W^1_\ell\in\R^{d\times d_{\rm ff}},\quad
W^2_\ell\in\R^{d_{\rm ff}\times d},\quad
b^1_\ell\in\R^{d_{\rm ff}},\quad b^2_\ell\in\R^d.
\end{equation}
For example, $\phi(z)=z\Phi(z)$ coordinatewise is GELU. Practical models
change normalization, gated MLPs, attention-head organization, and position
handling. The equations specify one complete pedagogical block, not the unique
modern design.

The key invariant is causal dependence: after $L$ blocks, row
$h_t^L=H^L_{t,:}$ depends only on $x_{<t}$.

\section{From a hidden vector to the next-token distribution}

Let $W_U\in\R^{d\times V}$ and $b_U\in\R^V$. The final row is converted to
logits and then to probabilities:
\begin{align}
z_t&=h_t^LW_U+b_U,\\
p_\theta(x_t=v\mid x_{<t})
&=\frac{\exp(z_{t,v})}{\sum_{u=1}^V\exp(z_{t,u})}.
\end{align}
Weight tying sets $W_U=E^\top$; it is common but not logically required.

The single-token path is therefore
\begin{equation}
e_{x_{t-1}}
\longrightarrow E_{x_{t-1},:}
\longrightarrow h_t^L
\longrightarrow z_t
\longrightarrow p_\theta(\,\cdot\mid x_{<t}).
\end{equation}
The contextual vector $h_t^L$ also depends on the earlier tokens through the
masked attention blocks.

\section{Autoregressive generation}

A sampled decoder draws
\begin{equation}
X_t\sim p_\theta(\,\cdot\mid X_{<t}),
\end{equation}
whereas greedy decoding chooses
\begin{equation}
X_t\in\arg\max_v p_\theta(v\mid X_{<t}).
\end{equation}
In either case the selected token is appended and the procedure repeats until
a stopping rule fires. Implementations cache keys and values from earlier
positions, so each generation step need not recompute the entire prefix.

Greedy decoding is neither sampling from the model nor, in general, global
optimization of the probability of the complete sequence. A locally most
probable token can lead to poor later continuations.

\section{What was said about training}

Training was described only in words. The system is shown many text prefixes
together with the tokens that actually followed them. Its predictions are
compared with those next tokens, and the shared weights are modified to improve
the predictions across the data. Lecture~3 will express this description using
probabilistic models, log loss, maximum likelihood, KL divergence, and
compression.

\section{Questions carried into homework}

\begin{enumerate}[leftmargin=*]
\item \textbf{Relative position.}  For block-rotation matrices $\mathcal R(t)$,
prove
\[
\mathcal R(s)^\top\mathcal R(t)=\mathcal R(t-s)
\]
and hence the RoPE identity
\[
(\mathcal R(s)q_s)^\top(\mathcal R(t)k_t)
=q_s^\top\mathcal R(t-s)k_t.
\]

\item \textbf{Greedy decoding.}  Construct a family of conditional
distributions for which repeated tokenwise argmax returns a sequence whose
probability is exponentially smaller in its length than that of the
maximum-probability sequence.
\end{enumerate}

\section{Take-home messages}

\begin{itemize}[leftmargin=*]
\item A decoder transformer maps a prefix to a categorical distribution by
embedding tokens, applying causally masked attention and positionwise
transformations, and using a softmax readout.
\item Absolute position embeddings are added once at the input. RoPE and
relative biases instead modify attention in every layer that uses them.
\item The learned conditional distribution and the decoding algorithm are
different objects. Tokenwise argmax does not solve a general sequence-level
optimization problem.
\item This lecture described inference. It did not yet explain why learning
produces useful parameters.
\end{itemize}
